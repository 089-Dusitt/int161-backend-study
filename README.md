# ห้องอ่าน Backend INT161

เว็บติวสอบ Basic Backend Development ภาษาไทย สำหรับอ่านบนคอมพิวเตอร์และมือถือ

**เปิดเว็บ:** https://089-dusitt.github.io/int161-backend-study/

- สรุปเนื้อหา 13 บท พร้อมสิ่งที่อาจารย์เน้นจาก G1/G2
- คำศัพท์ 110 คำ ค้นหาและแยกหมวดได้
- ข้อสอบฝึก 30 ข้อ พร้อมตรวจคำตอบและเหตุผล
- แบบฝึกอ่านโค้ด 5 ชุด และเขียน API 5 ชุด
- ทดลอง Pagination และแผนอ่านก่อนสอบ
- โหมดกลางคืน ปรับขนาดตัวอักษร และบันทึกความคืบหน้าในเบราว์เซอร์
- ดาวน์โหลดชุดเว็บสำหรับเปิดอ่านออฟไลน์ได้

## ประกาศกลางภาคที่นำมาอัปเดต 22 ตุลาคม 2026

- ทฤษฎี 52 ข้อ 50 คะแนน 1 ชั่วโมง Close Book และใช้ดินสอ
- ปฏิบัติ 6 ข้อ 1C/3R/1U/1D เน้น CRUD, DTO, Pagination, Exception Handling โจทย์รวม 110 คะแนน คะแนนเต็ม 100
- เอกสารปฏิบัติเตรียมก่อนสอบในช่วง 15 นาที ห้ามเชื่อมต่ออินเทอร์เน็ตระหว่างสอบ รับ/ส่งผ่าน LEB2
- 30 ข้อในเว็บยังเป็นแบบฝึก ไม่ใช่จำนวนข้อสอบจริง วันสอบและระยะเวลาปฏิบัติไม่ได้ระบุในข้อความประกาศที่ได้รับ
- ZIP ที่แนบตรวจเฉพาะโครงสร้างและเอกสาร ไม่รันหรือเผยแพร่ต้นฉบับ และยังไม่พบไฟล์ชื่อ midterm-exam-esm-template.zip ภายใน

แบบฝึกจัดทำเพื่อทบทวน ไม่ใช่ข้อสอบจริง กติกาสอบให้ยึดประกาศล่าสุดของรายวิชา

Repository นี้มีเฉพาะเว็บสรุป แบบฝึก และตัวตรวจข้อมูล ไม่รวม PDF หรือ transcript ต้นฉบับ ข้อมูลความคืบหน้าของผู้ใช้ หรือข้อมูลเชื่อมต่อบริการส่วนตัว

## ตรวจและเผยแพร่

```sh
node verify.mjs
```

ไฟล์เว็บอยู่ใน `dist/` เมื่อ push ไป `main` GitHub Actions จะตรวจข้อมูลและเผยแพร่ GitHub Pages โดยไม่ต้องติดตั้ง dependencies
